# Open Design Brief · 拍了就懂 · 识别结果页（手机）

> **用法：** 整份复制到 Open Design（桌面端 / `od` / 已接入 MCP 的 agent）。  
> **先绑定设计系统：** 使用仓库内 `design/DESIGN.md`（拍了就懂）。  
> **模板建议：** `mobile-app` 或 multi-screen mobile prototype · iPhone 15 Pro 框 · 390×844。  
> **输出：** 可点击的单页/多屏 HTML 原型（非 Streamlit）。

---

## Paste-ready prompt（复制从下一行开始）

```
使用 design/DESIGN.md（拍了就懂）作为唯一品牌契约。
生成「拍了就懂」App 的 mobile 高保真原型，iPhone 15 Pro 设备框。

# 产品
- 名称：拍了就懂
- 一句话：拍食品配料表，马上听懂能不能放心给家人吃
- 用户：60+ 老人 + 带娃家长；手机竖屏为主
- 原则：结论优先、大字适老、色+形双编码、不恐吓、不装医疗诊断

# 本任务范围
优先做 **1 个完整结果页（普通食品）**；可选附带极简「扫描成功 → 结果」过渡。
不要做桌面后台、不要做深色模式、不要堆 SaaS 仪表盘。

# 结果页信息架构（从上到下，顺序锁定）
1. 顶部导航：左返回 · 中标题「识别结果」
2. 分数摘要卡（score-hero）
   - 左：产品短名「某某饼干」；副文「配料表识别于 2026-08-01」
   - 右：大圆分数 72 + 文案「配料参考分」；状态环用 score-caution（橙）
   - 胶囊：▲ 有可留意项
   - 一句话：含少量需留意的成分，请结合自身情况查看
   - 底部免责：结果仅供参考，不能代替医生诊断…
   - 次按钮文案：慢速再读一遍
3. （可选条）个性化提醒 1 条示例：「含阿斯巴甜 · 与您档案中的关注项相关」——短标题+一行说明
4. 主 CTA 大按钮：**🔊 听结果**（高度 ≥48px，叶绿主色）
5. 添加剂清单卡片
   - 行按风险排序，示例数据：
     - 山梨酸钾 · 较友好 · ● 绿 · 防腐剂
     - 阿斯巴甜 · 注意 · ▲ 橙 · 甜味剂
     - 胭脂红 · 建议少吃 · ■ 红 · 着色剂
     - 某代号 · 待确认 · ▲ 橙 · 说明「标准收录中，风险级待补充」
   - 默认展示列表；底部「展开全部」
6. 一般饮食建议卡：1 段口语建议（勿医疗承诺）
7. 全部配料：标签云（小麦粉、白砂糖、植物油、山梨酸钾…）；不要再重复贴一整段相同 OCR
8. 底栏双按钮等宽：**再扫一个** | **返回首页**
9. 底部 Tab（App chrome）：首页 | 扫描(高亮可) | 历史 | 我的 — 内容区预留安全区

# 视觉硬约束（摘自 DESIGN.md）
- 背景 #FAFAF5，卡片白，主色 #2E7D32，注意 #FF9800，危险 #E53935
- 正文 ≥18px，产品名 ≥24px，分数 ≥48px
- 圆角 12–24px；卡片间距 16px；触控 ≥48px
- 状态必须同时有颜色 + 中文标签 + 形状（●▲■）
- 动效：分数 0→72 count-up 一次即可；禁止无限旋转
- 禁止：紫粉 AI 渐变、玻璃拟态堆叠、12px 脚注当主信息

# 文案语气
口语、短句。用「较友好/注意/建议少吃/待确认」，不要「A/B/C 级」「UNMATCHED」。

# 交付
1. 单文件或清晰分文件的 HTML/CSS 原型，手机框内可滚动
2. 若可生成 2 个方向：A「更温暖亲子」B「更冷静信息」——但字号与结构顺序不变
3. 在页面角落用小字标注：Prototype only · handoff → Streamlit components/score_hero.py + additive_card.py + voice_panel.py
```

## 进阶：三屏流（可选第二次 brief）

若第一次结果页满意，再贴：

```
在同一 DESIGN.md 下扩展为 3 屏 mobile flow（可左右滑动或底部点选）：
Screen 1 首页：大标题「拍了就懂」+ 一句副文 + 超大主按钮「拍配料表」+ 最近 1 条历史缩略
Screen 2 扫描：取景示意 +「对准配料表」+ 拍照/相册 + 模糊重拍提示条
Screen 3 结果：沿用已确认的结果页结构
保持适老字号与主色不变。不要加登录墙。
```

## 验收清单（点原型时勾选）

- [ ] 首屏不滚动即可看到：产品名 + 分数 + 状态胶囊 +「听结果」
- [ ] 老人臂长模拟：主按钮易点，非细文字链
- [ ] 色弱：关掉颜色仍能靠「较友好/注意/建议少吃」+ 形状区分
- [ ] 免责在，但不压过结论
- [ ] 无「保证安全 / 可治疗」用语
- [ ] 与 `DESIGN.md` 色板一致（抽查 primary #2E7D32）

## 冻结后如何回灌产品（工程备忘）

| 原型块 | Streamlit 落点 |
|--------|----------------|
| 分数卡 | `components/score_hero.py` + `.streamlit/style.css` `.score-card*` |
| 听结果 | `components/voice_panel.py` |
| 添加剂行 | `components/additive_card.py` |
| 区块顺序 | `pages/result.py` → `render_food_page` |
| Token | `.streamlit/style.css` `:root` 与 `design/DESIGN.md` 双写同步 |

**原则：** 一次只搬「顺序 + 文案 + token + 1–2 个关键卡片样式」，不重写整站框架。
